# Shopping List Management

## Goal
Verify high-level management of the lists themselves.

## Test Cases
1. **Rename List**: Verify that a user can change the name of an existing shopping list from the dashboard.
2. **Delete List**: Verify that deleting a list removes it from the dashboard and cleans up associated items.
3. **Category Filtering**: Verify that selecting a specific category filter only shows items belonging to that category.
