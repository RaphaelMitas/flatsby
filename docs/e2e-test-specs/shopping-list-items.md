# Shopping List Items

## Goal
Verify the lifecycle of individual items within a specific shopping list.

## Test Cases
1. **Add Item**: Verify that adding an item with a name and manual category adds it to the active items list.
2. **Complete Item**: Verify that checking an item moves it from the "Active" section to the "Purchased" section.
3. **Undo Completion**: Verify that unchecking a purchased item moves it back to the active list.
4. **Edit Item**: Verify that renaming an existing item updates the text correctly.
5. **Delete Item**: Verify that removing an item deletes it from the list immediately.
