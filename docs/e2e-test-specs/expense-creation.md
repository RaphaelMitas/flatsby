# Expense Creation

## Goal
Verify that expenses can be created with various split methods.

## Test Cases
1. **Equal Split**: Verify creating an expense where the cost is split equally among all group members.
2. **Percentage Split**: Verify creating an expense where members pay specific percentages.
3. **Custom Amount Split**: Verify creating an expense where specific amounts are assigned to each member.
4. **Manual Categorization**: Verify that users can manually select a category for the expense.
